# 15 Phase plan

Covers the whole system. Each phase ends with something usable, its acceptance
criteria, and what the admin can configure at that point. Phases are sequential;
work inside a phase is parallel across roles (`docs/team/roles.md`).

## Status as of 2026-10-14

Each phase is **Done** (the whole scope exists and a test, a route or a record shows it) or
**Partial** (it exists, and the part that is missing is named). "Done" never means "run in
production": nothing has been, and the rows say what has only been exercised against a fake. The
sentence-by-sentence inventory is [claims-2026-10.md](../team/claims-2026-10.md); the security pass is
[security-verification-2026-10.md](../team/security-verification-2026-10.md); what is left for the
owner is in [RELEASE-NOTES.md](../RELEASE-NOTES.md).

**Phase 4 in detail.** Built: object storage behind a port, file upload with per-tenant type and
size limits, ingestion as a job (text extraction for PDF, DOCX, XLSX, CSV, Markdown and plain text;
image description through `vision_ingest`; a summary; chunks; optional embeddings), the summary
carried in the interviewer's context every turn with chunks recalled on demand, recorded voice as a
single request that stores the audio, transcribes it and streams the turn back, audio kept and
playable, and a retention clock of its own for recordings. The live voice cascade (FR-30a) is built: a WebSocket carries the participant's speech in, the
same turn the text interview runs decides what to ask, and the interviewer's voice streams back,
with barge-in, live captions, the voice signals traced per call, and a fallback chain that degrades
to captions and then to typing without losing the session.

**Streaming captions (D-77).** With an `stt_stream` route the browser streams PCM16 at 24 kHz and
the provider's realtime transcription socket (OpenAI's, through `Provider.transcribeStream`)
captions the participant while they talk; its final transcript takes the turn. Without that route,
or when the socket fails, the call transcribes per utterance as before (D-70), so a caption appears
when the participant stops. An admin turns live voice on from Settings → Voice, and is asked for an
OpenAI key when the routes are missing.

Deployment is covered by `docs/DEPLOY.md` and `deploy/compose.prod.yml`, which is outside the
phase table because it is not a feature: it is how any of the above reaches a server.
