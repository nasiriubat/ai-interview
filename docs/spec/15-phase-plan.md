# 15 Phase plan

Covers the whole system. Each phase ends with something usable, its acceptance
criteria, and what the admin can configure at that point. Phases are sequential;
work inside a phase is parallel across roles (`docs/team/roles.md`).

| Phase                                | Scope                                                                                                                                                                                                                                                                                                        | Acceptance                                                                                                                                                                              | Admin can configure                                                          |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| 0 Foundations (done in part)         | Monorepo, CI, provider and cost layer, database schema, RLS, seeds                                                                                                                                                                                                                                           | Tests and evals run in CI; migrations apply to a live Postgres                                                                                                                          | Nothing yet                                                                  |
| 1 Core interview, text and options   | API with auth and tenancy; templates module and settings service; campaigns with invitations, share links, email codes, anonymous hashes; engine with turn objects and widgets; layered context; extraction; participant web UI (arrival, consent, chat, options, resume, summary, delete); tracing and logs | An employee completes `opportunity_discovery` end to end on a phone; facts extracted; replay works; cost visible per session                                                            | Templates, prompts, campaign defaults, providers, routing, budgets, branding |
| 2 Analysis and report                | Embeddings, clustering, seven-factor scoring, k-anonymity, report with process maps, results dashboard with admin overrides, Kroki PDF; languages beyond English (Finnish first)                                                                                                                             | Five interviews produce a report an admin acts on; "none" outcomes appear when warranted; department comparison respects k                                                              | Weights, thresholds, k, report sections, languages                           |
| 3 Requirements interview             | Path selection, context block, issue detection, MVP challenge, live spec editor with diagrams, exports (Markdown, JSON, PDF, agent bundle, GitHub push), chaining from opportunities, external invitations                                                                                                   | This spec is regenerated by the product from a rough prompt and diffs cleanly against these documents; a coding agent builds a sample feature from the bundle without asking a question | Aggressiveness, cadence, sections, bundle format                             |
| 4 Voice and files                    | Recorded voice, file ingestion with recall, real-time voice cascade with barge-in and captions, fallback chain, voice metrics                                                                                                                                                                                | Interview completed entirely by live voice on a phone; first word under 1.5 s at p95                                                                                                    | Voice providers, latency targets, file types                                 |
| 5 Admin depth and operations         | Full stats dashboard, spend analytics, prompt canaries, feature flags, notifications, audit views, job admin, backups and restore drill, load and chaos tests, SLO dashboards                                                                                                                                | SLOs met under load; provider outage handled gracefully; restore drill passes                                                                                                           | Everything in `07`                                                           |
| 6 Integrations                       | SSO (SAML, OIDC), Slack and Teams entry points, Jira and Linear export, webhooks, public API keys                                                                                                                                                                                                            | A customer signs in with SSO and exports a spec to Jira                                                                                                                                 | Integration settings per tenant                                              |
| 7 Collaboration and speech-to-speech | Second person in a requirements session, comments on spec sections, speech-to-speech adapter with the "ask the interviewer" tool                                                                                                                                                                             | Two users complete a spec together; speech-to-speech passes the same evals as cascade                                                                                                   | Collaboration flags, voice adapter choice                                    |
| 8 Commercial                         | Billing, self-serve company sign-up, plan limits, usage-based invoicing from the ledger, mobile-friendly PWA install                                                                                                                                                                                         | A new company signs up, pays, and runs a campaign without operator help                                                                                                                 | Plans, limits, pricing                                                       |

Every phase: evals extended, docs updated, migration reversible, release notes, and
the admin "what changed" panel updated from the settings catalog.
